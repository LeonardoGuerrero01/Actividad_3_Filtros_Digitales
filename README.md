Actividad Formativa 3: Implementación y evaluación de filtros digitales
Descripción del proyecto
Este proyecto consiste en diseñar e implementar filtros digitales FIR e IIR utilizando Python. Se trabaja con una señal compuesta por diferentes frecuencias a la que se agrega ruido blanco, con el propósito de observar cómo actúan los filtros digitales.

Objetivo
Implementar filtros pasa bajos, pasa altos y pasa bandas para analizar su comportamiento y comparar sus resultados mediante gráficas y respuestas en frecuencia.

Herramientas utilizadas
•Python
•NumPy
•SciPy
•Matplotlib

Filtros implementados
Se diseñaron los siguientes filtros:
•FIR pasa bajos.
•FIR pasa altos.
•FIR pasa bandas.
•IIR pasa bajos.
•IIR pasa altos.
•IIR pasa bandas.

Resultados
El programa genera tres imágenes:
1.resultados_IIR.png: muestra los resultados de los filtros IIR.
2.resultados_FIR.png: muestra los resultados de los filtros FIR.
3.respuesta_frecuencia_completa.png: compara la respuesta en frecuencia de los filtros implementados.

Ejecución del programa
Para ejecutar el proyecto es necesario tener instaladas las bibliotecas utilizadas.
pip install numpy scipy matplotlib
Después, se ejecuta el archivo mediante el siguiente comando:
py filtros_digitales.py

Conclusión
La simulación permitió comprobar el funcionamiento de los filtros digitales FIR e IIR y observar cómo pueden conservar o atenuar diferentes componentes de frecuencia de una señal. Python facilitó el diseño, la implementación y el análisis de los resultados.
